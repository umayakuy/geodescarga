Descarga Datos Geoespaciales de Bolivia

La fuente de datos proviene del repositorio "Geodatos" de Mauricio Foronda, quien desarrolló un sistema en línea alojado en GitHub que realiza un monitoreo continuo de datos geoespaciales, registrándolos y generando copias de respaldo automáticas en Archive.org.

Felicitamos y agradecemos este valioso esfuerzo orientado a la preservación y disponibilidad de los datos geoespaciales de Bolivia. Como apoyo a esta iniciativa, desarrollamos esta aplicación para facilitar el acceso a esta información.
